# Starlight Academy learning plugin

Five skills and eight local, read-only MCP tools for four practice missions.
Preserve an initial attempt, assistance, artifact, critique, revision and transfer.
The server uses bundled public examples. It makes no network calls or external actions.
Practice is unsigned self-study, not certification or permission to act.
