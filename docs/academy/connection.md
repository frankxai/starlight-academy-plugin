# Starlight Academy conversation plugin

One guiding skill and four public HTTP MCP tools connect eight fictional teaching methods and four challenges to your AI host. The host supplies the conversation; no Academy account, model key or learner database is used. Work stays subject to your host's privacy policies.

[Choose a challenge and connect](https://starlightintelligence.academy/academy/connect).

## Codex

```sh
codex plugin marketplace add frankxai/starlight-academy-plugin --ref main
codex plugin add starlight-academy@starlight-academy
```

## Claude Code

```sh
claude plugin marketplace add frankxai/starlight-academy-plugin
claude plugin install starlight-academy@starlight-academy
```

If you already registered this marketplace at an older revision, use your host's marketplace update command or use the complete downloadable connection archive as a separate local marketplace. Do not silently replace another registered source. Open a fresh conversation after installation.

Ask: Use Starlight Academy to help me choose a challenge. Ask for my first attempt, offer one hint at a time, critique my evidence and test transfer.
