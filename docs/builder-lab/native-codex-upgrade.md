# Current Codex plugin update and recovery check

On 2 October 2026, Codex CLI 0.159.3 installed the accepted Builder Lab 0.1.3
source and updated the same owned local selector to 0.1.5. All twelve older and
thirteen current cached payload files matched their immutable Git blobs.
This was native local CLI behavior with no model call. The
[machine-readable receipt](native-codex-upgrade.json) records source hashes,
phases, recovery and limitations. Its independent evidence review is pending.

| Phase | Observed result |
| --- | --- |
| Install 0.1.3 | Twelve exact cached files; three rendered skill descriptors |
| Update to 0.1.5 | Thirteen exact cached files; three rendered skill descriptors |
| Disable current plugin in a temporary profile | Zero rendered target descriptors |
| Execute the installed 0.1.5 restore tool | Ten Quote Desk source files restored and readable |
| Existing destination and wrong hash | Exit 1; prior source/note preserved; wrong-hash output absent |
| Native targeted removal | Zero rendered target descriptors; owned plugin cache/profile absent |
| Final configuration | Global configuration bytes and semantics equal the pre-install snapshot |

The test used one temporary local marketplace and the documented native CLI
`plugin add` and `plugin remove` commands. Source selection was scoped through
command-line marketplace overrides; the permanent Academy catalogs were not
changed. Other configured plugins were disabled in an owned temporary profile,
and MCP and browsing were disabled in the diagnostic calls. Other skill
descriptors remained. This establishes local discovery diagnostics, not a pure
host, model use, access revocation or broad trigger quality.

The checker resolves Codex's displayed skill-root aliases to the installed cache
and verifies the selected version. Its first attempt incorrectly searched
descriptor lines for literal cache paths; that checker failure and successful
cleanup remain recorded separately. The retry preserved older source and a
customer note while selecting the current version.

The installed cached restore tool ran under the ordinary maintaining account on
the previously checksum-bound ten-file Quote Desk source package. The lead then
compared every restored file with the archive bytes. Existing destination and
wrong-hash checks preserved their return codes and filesystem assertions; raw
refusal messages were not retained. This check authored no new buyer wording.
The separate [completed Codex workflow](native-codex-completion.md) records
creation, editing, reopening, export and verification.

Seven native CLI commands completed successfully, followed by configuration and
cache checks. This deterministic check adds no model receipt or model-token
total. Invoice allocation and cash ROI remain unknown. It does not establish
outside-user usefulness, the full current two-host suite, native interrupted
agent recovery, Dots access, directory approval or a paid release.
