# Does our workflow improve delivery time?

*Draft for discussion*

**Decision:** We cannot yet determine whether the workflow improves delivery time. Defer claims of improvement until a comparable baseline and workflow measurements are available. This is an evidence gap, not evidence that the workflow has no effect.

## What we know

No sources, measurements, baseline, dates or workflow description were supplied. We cannot estimate time saved, identify the cause of any change or assess whether faster delivery comes with more rework.

The hypothesis to test is: **the workflow reduces the time from an agreed starting point to accepted delivery, while maintaining quality.**

## Evidence needed for a decision

Compare work completed under the previous process with comparable work completed using the workflow. Use the same start and finish definitions for both groups, and account for differences in task complexity, staffing and dependencies.

Measure:

- **Delivery time:** elapsed time from the agreed start to accepted delivery.
- **Quality:** rework, reopened work or defects after delivery.
- **Workflow cost:** additional setup, review and maintenance effort.

Report the number of items and median delivery time for each group, alongside the spread of results. A faster median alone can conceal slow cases or a shift toward easier tasks. A historical comparison can show an association; it may not establish that the workflow caused the change.

## Recovery action

Request the smallest useful evidence packet: a brief workflow description and anonymized records for comparable completed items from both processes. Each record should contain the process used, start and acceptance timestamps, task type or complexity, and rework or defect information.

If historical records are unavailable, propose a prospective comparison for authorization. Agree on measurement definitions and a meaningful improvement threshold before collecting results. No research or collection has been performed.

## Decision rule

Support broader use when comparable results show a meaningful reduction in delivery time without unacceptable quality or operating costs. If results are mixed, identify which kinds of work benefit and test that narrower use. If evidence remains insufficient, retain an explicitly provisional conclusion.
